# gg_pywords_game
파이썬 워드 게임
## 코드 구성
> main
1. word.txt파일의 단어들을 모두 나열 후 "준비? 엔터를 입력하세요." 출력
2. 시작 시간 기록
3. `scorePrint`를 호출하여 게임을 진행하고 맞춘 개수를 return 값 받기
4. 종료 시간 기록
5. 총 걸린 시간을 계산 후 마지막에 걸린시간과 맞춘 개수를 출력
> function
- `scorePrint`
    - 전체 맞춘 개수를 counting
    - `gameRun`의 결과에 따라서 맞추었을 경우 순차적으로 result를 하나씩 증가시킨다.
        - `gameRun`에서 1을 리턴할 경우 맞춘 경우로 1을 증가시킨다.
        - `gameRun`에서 0을 리턴할 경우 틀린 경우로 0만큼 증가시킨다.(즉 맞춘 개수에 변화 X)
- `gameRun`
    1. 단어를 랜덤으로 생성
    2. 단어를 맞출 경우
        - "맞춰서~"라는 문구와 함께 맞추었다는 소리 송출
        - 1 return
    3. 단어를 틀렸을 경우
        - "못맞춰서~"라는 문구와 함께 틀렸다는 소리 송출
        - 0 return
    </br>&rightarrow; return하는 값은 맞춘 개수
